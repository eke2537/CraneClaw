# CraneClaw

クレーンゲームの爪を、サーボ 2 個で滑らかに開閉する Arduino ライブラリです。

- 左右の爪を 1 個ずつのサーボで動かし、いつも同じ力で開閉する
- 爪を**ばね越し**に閉じる機構に向けて、つかむ力を「ばねの巻き量」で指定する
- 動き始めと止まる前をゆっくりにした、滑らかな動き
- クレーンゲームらしい「運ぶ途中で確率で力が弱まる」動きを関数 1 つで使える
- 呼んだらすぐ戻る作り(ノンブロッキング)なので、モーターなどほかの処理と同時に動かせる

## 1. 対応するボードと必要なもの

| 項目 | 内容 |
|---|---|
| ボード | Raspberry Pi Pico などの RP2040(arduino-pico)で確認。Arduino Uno(AVR)でもビルドが通ることを確認(動作は未確認) |
| 依存するライブラリ | `Servo`(arduino-pico では付属のもの、AVR などでは Arduino 標準の Servo) |
| サーボ | 周期 20ms・パルス幅で角度を決める一般的なサーボ（SG90など）|

確認した環境: arduino-cli、arduino-pico 6.3.0(ボード Raspberry Pi Pico)と Arduino AVR(Arduino Uno)。

## 2. インストール

1. `CraneClaw` のフォルダーを、フォルダーごと Arduino のスケッチブックの `libraries` フォルダー(Windows なら `ドキュメント\Arduino\libraries`)にコピーする
2. Arduino IDE を起動し直す

`CraneClaw` のフォルダーを ZIP にして、Arduino IDE の「スケッチ」→「ライブラリをインクルード」→「.ZIP 形式のライブラリをインストール」で選んでもかまいません。

入れた後は、「ファイル」→「スケッチ例」→「CraneClaw」から例を開けます。

| 例 | 内容 |
|---|---|
| `BasicMotion` | 閉じる → 弱めの判定 → 開く を繰り返し、位置をシリアルモニタに出す |
| `Calibration` | シリアルモニタから 1 文字ずつ送ってサーボを少しずつ動かし、調整値を探す(6 章) |

## 3. 配線

| サーボの線 | つなぐ先 |
|---|---|
| 信号(SG90 は橙) | マイコンの端子(`begin` で指定) |
| 電源(SG90 は赤) | サーボ用の 5V(マイコンの 3.3V からは取らず、外部電源を推奨) |
| GND(SG90 は茶) | マイコンと共通の GND |

サーボには動き始めや拘束時に大きな電流が流れます。電源の近くに大きめのコンデンサーを入れてください。

## 4. 基本的な使い方

```cpp
#include <CraneClaw.h>

CraneClaw claw;

const CraneClawConfig CONFIG = {
    {1133, 1450, 1450},  // 左: 開いた角度・閉じきる角度・最大の角度(µs)
    {1767, 1450, 1450},  // 右
    80,                  // つかむ力(0〜100)
    30,                  // 運ぶ力(0〜100)
    30,                  // 弱める確率(%)
    800, 800, 500,       // 開く・閉じる・弱める時間(ms)
};

void setup() {
    claw.begin(22, 23, CONFIG);  // 左の端子、右の端子、設定
    claw.signalOn();             // 信号を出し始める(爪が閉じきる角度から)
    claw.openArm();              // 開く
}

void loop() {
    claw.loop();                 // これを毎回呼ぶ。呼ばないと爪が動かない
}
```

`openArm()` などは「動き始めの合図」を出すだけで、すぐ戻ります。実際に少しずつ動かすのは `claw.loop()` です。`loop()` の中で `delay()` を使うと、その間は爪が止まるので注意してください。

## 5. 動作の仕組み

### 5.1　機構

この機構では、サーボと爪の間にばねがあります。

- サーボを「閉じきる角度」まで回すと、何もつかんでいなければ爪がちょうど閉じきります
- さらに先へ回すと、爪は止まったままでばねが巻かれ、閉じる力が強くなります
- つかむ力 0〜100 は、「閉じきる角度」から「最大の角度」までを直線で割り当てた位置です
- 景品が大きくて爪が早く止まっても、角度の差はばねが受けるので、プログラムを直す必要はありません(同じ力の指定でも、大きい景品ほどばねが多く巻かれ、少し強くなります)

（ばねのない機構の場合は `maxArm` を `closeArm` と同じにします。）

### 5.2 滑らかな動き

- 指令は 20ms に 1 回だけ更新します。サーボは 20ms ごとにしか幅を読まないため、それより細かく変えても意味がありません
- 進み具合は (1 − cos(πt)) / 2 で決めます(t は経過時間の割合 0〜1)。動き始めと止まる前の速さが 0 になり、途中の最高速度は一定の速さで動かす場合の約 1.57 倍です
- 進み具合は経過時間で決めるので、`loop()` を呼ぶ間隔がぶれても、かかる時間は変わりません
- 信号を出し始めるときは、最初のパルスから「閉じきる角度」を出します(位置を決めずに出すと、サーボが急に動くため)
- 信号を止めるときは、出しているパルスを出し終えてから止めます

この作り方は、Arduino で広く使われているサーボの加減速のライブラリ ServoEasing(ArminJo)に合わせました(20ms ごとの更新、SINE の IN_OUT のカーブ、初めの位置を決めてから出すこと)。

### 5.3 確率

クレーンゲームでは、景品を運ぶ途中で爪の力が弱まることがあります。`maybeWeaken()` を呼ぶと、設定した確率で当たり外れを決め、当たれば「運ぶ力」まで `weakenTimeMs` をかけて緩めます(一気に緩めると景品が落ちやすいため)。

- 閉じている間だけ判定します。1 回当たると、次に `closeArm()` を呼ぶまでは何度呼んでも判定しません
- 1 プレイで 2 回呼ぶと、弱まる確率は 1 − (1 − p)² になります(p = 30% なら 51%)

## 6. 調整値の決め方

組み立ての差でサーボの角度は 1 台ごとに変わるため、左右それぞれ 3 つの値を実機で探します。例の `Calibration` を使います。

1. `Calibration` を書き込み、シリアルモニタ(115200bps)を開く
2. `l` で左を選び、`+` `-`(10µs)と `]` `[`(100µs)で動かして、次の位置の値を記録する
   - **閉じきる角度**: 何もつかまずに、爪がちょうど閉じきった位置
   - **開いた角度**: 爪がいちばん開いた位置
   - **最大の角度**: 閉じきる角度からさらに進め、ばねが巻き切られて固くなる**手前**
3. `r` で右も同じように探す
4. 記録した値を、自分のスケッチの `CraneClawConfig` に書く

**注意点**

- 最大の角度は、サーボがそれ以上回れない位置(ばねが巻き切られた位置や、サーボの可動範囲の端)の手前に置いてください。そこまで指令するとサーボが拘束され、大きな電流が流れ続けて熱くなります
- 左右のサーボが向かい合って付いている場合、閉じるときの回転は左右で逆になります。値の大小が左右で逆になってかまいません(ライブラリは大小を問いません)

## 7. 関数一覧

### 7.1 設定

```cpp
struct CraneClawAngles {
    uint16_t openArm;   // 開いた角度(µs)
    uint16_t closeArm;  // 閉じきる角度(µs)。つかむ力 0
    uint16_t maxArm;    // 最大の角度(µs)。つかむ力 100
};

struct CraneClawConfig {
    CraneClawAngles left, right;  // 左右の調整値
    uint8_t gripPower;            // つかむ力 0〜100
    uint8_t carryPower;           // 運ぶ力 0〜100(弱めが当たったときの力)
    uint8_t weakenPercent;        // 弱める確率 0〜100(%)
    uint32_t openTimeMs;          // 開くのにかける時間(ms。0 ならすぐ)
    uint32_t closeTimeMs;         // 閉じるのにかける時間
    uint32_t weakenTimeMs;        // 弱めるのにかける時間
};
```

範囲外の値は丸めます(パルス幅は 500〜2400µs、力と確率は 0〜100)。

### 7.2 関数

| 関数 | 説明 |
|---|---|
| `void begin(uint8_t leftPin, uint8_t rightPin, const CraneClawConfig &config)` | 最初に 1 回呼ぶ。左右のサーボの端子と設定を受け取る。信号はまだ出さず、端子は L |
| `void signalOn()` | サーボに信号を出し始める。左右とも「閉じきる角度」から始める。すでに出しているときは何もしない |
| `void signalOff()` | 信号を止める。出しているパルスを出し終えてから止まり、端子は L になる |
| `bool isSignalOn()` | 信号を出していれば true |
| `void openArm()` | 「開いた角度」まで `openTimeMs` をかけて開く |
| `void closeArm()` | つかむ力の位置まで `closeTimeMs` をかけて閉じる。弱めの状態を戻す |
| `void restArm()` | 「閉じきる角度」(つかむ力 0)まで `closeTimeMs` をかけて閉じる。信号を止める前に使う(ばねを巻いたまま止めないため) |
| `void setGripPower(uint8_t power)` | つかむ力を変える。閉じていて弱めていないときは、`closeTimeMs` をかけてその場で反映する |
| `bool maybeWeaken()` | 確率で弱める。当たって緩め始めたら true。閉じていないとき・すでに弱めたときは判定せず false |
| `void moveToPulse(uint16_t leftUs, uint16_t rightUs)` | 調整用。左右のパルス幅を直接指定し、`closeTimeMs` をかけて動かす |
| `void updateConfig(const CraneClawConfig &config)` | 設定を差し替える。今の位置はそのままで、次に動かすときから効く |
| `const CraneClawConfig &config()` | 今の設定(丸めた後の値)を返す |
| `void loop()` | `loop()` の中で毎回呼ぶ。20ms ごとに指令を少しずつ動かす |
| `bool isMoving()` | 動いている途中なら true。動き終えるのを待つときに使う |
| `bool wasWeakened()` | 閉じてから弱めが当たっていれば true |
| `void getPosition(uint16_t &leftUs, uint16_t &rightUs)` | 今の指令(パルス幅)。信号を止めている間は 0 |

`openArm()`・`closeArm()`・`restArm()`・`moveToPulse()` は、信号を止めている間に呼んでも何もしません。動いている途中に別の動きを指示すると、今の位置から新しい目標へ動き直します。

## 8. 使い方の例: クレーンゲームの 1 プレイ

```cpp
// ボタンなどでプレイが始まったとき
claw.signalOn();

// 下降の前
claw.openArm();
// → claw.isMoving() が false になったら下降を始める

// 景品に着いたら
claw.closeArm();
// → claw.isMoving() が false になったら少し待って上昇

// 上昇し終えたとき(1 回目)と、獲得口へ戻る途中(2 回目)
claw.maybeWeaken();

// 獲得口の上に着いたら
claw.openArm();
// → 開き終えて少し待ったら
claw.restArm();
// → 閉じ終えたら
claw.signalOff();
```

待つときは `delay()` を使わず、`millis()` と比べて待ってください。`delay()` の間は `claw.loop()` が呼ばれず、爪が止まります。

## 9. 注意事項

- `loop()` を呼ばないと爪は動きません
- サーボを動かさない間は `signalOff()` で信号を止めることを勧めます。マイコンだけが動いていてサーボの電源が切れているときに、信号をかけ続けないためです
- 弱めの判定には Arduino の `random()` を使います。起動のたびに違う結果にするには、`setup()` で `randomSeed()` を呼んでください(RP2040 なら `randomSeed(rp2040.hwrand32())`)
- サーボが景品に当たって指令の角度まで回れない間は、サーボに大きめの電流が流れ続けます
